# TapCard Pro v3.0

**Complete WordPress Plugin for NFC + QR Digital Business Cards**

## Features

✅ Easy profile creation  
✅ Beautiful responsive design  
✅ REST API support  
✅ No database conflicts  
✅ Lightweight & fast  
✅ Production ready  

## Installation

1. Upload the plugin to `/wp-content/plugins/`
2. Activate in WordPress Admin
3. Go to Settings → Permalinks → Save (to flush rewrite rules)
4. Create your first profile

## Usage

1. Go to **TapCard Profiles** → **Add New**
2. Fill in your information
3. Copy the generated URL
4. Share the URL or scan the QR code
